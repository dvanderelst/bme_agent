Students are working on **color vision**. They learn about human color vision (rods, cones, and trichromacy) and how color is built by comparing multiple channels. They complete the color vision games — the RGB Codebreaker and Color Constancy browser games (local HTML) and the goggle color-discrimination game — and then build a robot with color vision from filtered light sensors. The default robot is **dichromatic**: two filtered light sensors (like a dog), the same idea as the goggles; a third filter can be added for full RGB. Students are split into two groups working on two robot challenges — **Color Mimicking** (match an LED bar's color with the onboard LED ring) and **Approach / Avoid** (drive toward one color and away from another). Refer to the color vision documentation for activity details, the sensor tables, and calibration guidance.
