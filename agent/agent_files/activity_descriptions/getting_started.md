Today, students are getting started with the robot — there is no biology component yet. They build the robot from the kit, pair it wirelessly with its USB dongle, connect to it in mBlock, and write their first programs. They learn the basic program structure used in every later activity (initialize, then loop: get sensor data → process → decide → act) and the idea of variables. Their two first programs are: blink the onboard LEDs on and off, and blink the LEDs whenever the onboard light sensor reads below 500 (which introduces variables and an if-decision). Optional challenges use the sonar (ultrasonic) and gyroscope sensors. The big idea is to get every student to a working, connected robot and comfortable with the basics of mBlock before the animal-behavior modules begin.

Students may ask about: building the robot and the simplified screws (short vs. long), pairing the dongle and reading its LED states (rapid flash, slow flash, solid blue), adding the robot in mBlock and connecting, the basic program structure, using variables, the onboard light sensor (0–1000) and the blink-when-dark program, and the sonar/gyroscope challenges (drive-and-stop, maintaining a fixed distance, the LED distance indicator, and using the robot as a level).
